# Ladder Web IDE

A web-based ladder logic diagramming tool specialized for PLC programming with multi-vendor export support.

**Core Value Proposition**: Draw once → Export to any PLC vendor format

## Features

- **Visual Editor**: Drag-and-drop interface for creating ladder diagrams
- **Component Library**: Contacts (NO/NC), Coils (Output/Set/Reset), Timers (TON/TOF/TP), Counters (CTU/CTD), Branches
- **Multi-Vendor Export**: Export to Keyence KV, Siemens STL, and more
- **Undo/Redo**: Full history support with keyboard shortcuts
- **Save/Load**: Save projects as JSON files, auto-save to browser storage
- **Validation**: Real-time error and warning detection
- **Responsive**: Works on desktop and tablet browsers

## Quick Start

### Using Docker (Recommended)

```bash
# Clone the repository
git clone <repo-url>
cd ladder-web-ide

# Start development server
docker compose up -d

# Open http://localhost:5173
```

### Manual Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Usage

### Creating a Ladder Diagram

1. **Drag components** from the left palette to the canvas
2. **Click to select** elements and edit variable names inline
3. **Connect elements** by dragging from handles (circles on element edges)
4. **Delete elements** by selecting and pressing Delete key

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Del` | Delete selected element |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+S` | Save |

### Variable Naming Convention

| Prefix | Type | Example |
|--------|------|---------|
| X | Input | X0, X1, X2 |
| Y | Output | Y0, Y1, Y2 |
| M | Memory bit | M0, M1, M2 |
| T | Timer | T0, T1, T2 |
| C | Counter | C0, C1, C2 |

### Exporting to PLC Format

1. Click **Export** button in toolbar
2. Select your PLC vendor (Keyence KV Series supported)
3. Click **Generate Preview** to see the output
4. Click **Export & Download** to save the file

## Supported Export Formats

## Development

### Tech Stack

- **Frontend**: React 18 + TypeScript
- **Diagramming**: React Flow
- **State Management**: Zustand
- **Styling**: Tailwind CSS
- **Build Tool**: Vite

### Adding a New Exporter

1. Create a new exporter in `src/core/compiler/`:

```typescript
// src/core/compiler/siemens.ts
import type { LadderExporter } from './types';

export class SiemensExporter implements LadderExporter {
  name = 'Siemens S7';
  vendor = 'siemens';
  fileExtension = '.stl';

  export(project: LadderProject): string {
    // Generate Siemens STL format
    return '...';
  }
}
```

2. Register in `src/core/compiler/index.ts`
3. Add vendor info to `VENDOR_INFO` in `types.ts`
